# Goodnotes toolbar glyphs

Original SVG geometry from static Goodnotes frontend assets available in the installed Goodnotes for Windows 2.4.5.0 application. Goodnotes Limited owns these assets.

The SVG path and shape coordinates are retained. Paint styles use CSS variables to reproduce the original monochrome and selected color states within PaperNote. No Goodnotes application code or user notebook data is included. Source URLs and geometry hashes are recorded in sources.json.
